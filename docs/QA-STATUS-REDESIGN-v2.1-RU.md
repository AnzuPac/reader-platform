# QA-статус дизайн-прохода TeroLibrary v2.1

Дата: 26.11.2026

## Что проверено в текущей среде

- ZIP исходного проекта прошёл проверку целостности и был распакован.
- TypeScript/TSX синтаксический transpile-проход выполнен для 342 `.ts`/`.tsx` файлов: 0 синтаксических ошибок.
- CSS `styles/design-system-v2.css` разобран через `tinycss2`: 0 parse errors.
- Визуальные концепты экспортированы в PNG для основных страниц в phone/desktop форматах, а также для светлой и тёмной темы.
- Скриншоты визуально просмотрены для главной, каталога, фильтров, карточки произведения, читалки и кабинетов автора/издательства.

## Что НЕ проверено

- `tsc --noEmit` — не запускался.
- Vitest / `npm test` — не запускались.
- `npm run build` — не запускался.
- Браузерный e2e и фактический снимок работающего Next.js приложения — не выполнялись.
- APK не пересобирался; Android WebView на физическом телефоне не тестировался.

Причина: в среде Node `22.16.0`, тогда как `package.json` проекта требует `22.22.2+` в ветке Node 22; зависимости в рабочую копию не установлены.

## Рекомендуемый приёмочный прогон

1. Node.js `22.22.2+`.
2. `npm ci`.
3. `npm run check` (если script в package соответствует handoff) и/или отдельные `npx tsc --noEmit`, `npm test`, `npm run build`.
4. Проверка SR/RU/EN и ćirilica/latinica.
5. Проверка light/dark.
6. Проверка на 390, 768 и 1440 px.
7. Поиск: title, author, transliteration, tags/fandom, history, pagination. Отдельно закрыть поиск по полному описанию: текущий `search_norm` его не индексирует.
8. Фильтры: include all/any, exclude, три AI-чекбокса, reset/submit, URL после refresh.
9. Состояния гостя и авторизованного аккаунта.
10. Читалка: доступ к главе, прогресс, TTS-права, комментарии, bottom bar и safe-area.
11. Author/Publisher роли и права: цифры и таблицы только из фактических данных, издательская статистика не должна захватывать selfpub автора.
12. Android WebView: keyboard, scroll, safe-area, viewport и нижняя навигация.

Не помечать сборку, тесты или WebView QA как успешные до фактического прогона.
