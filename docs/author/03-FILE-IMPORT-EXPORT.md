# Файлы, импорт и экспорт

## Поддержка импорта
Первичная матрица:
- DOCX — прямая обработка;
- DOC — безопасная конвертация, либо понятное сообщение с рекомендацией сохранить как DOCX/ODT;
- TXT — кодировки UTF-8/UTF-16 с определением и предупреждением;
- RTF, ODT — конвертация/парсер;
- EPUB — отдельный парсер с оглавлением;
- HTML/HTM — санитизация и очистка опасных элементов;
- Markdown — заголовки и разметка;
- PDF — извлечение текстового слоя; сканы отклонять с объяснением до появления OCR;
- FB2 — XML-парсер с обработкой метаданных и секций;
- ZIP — пакетная загрузка поддерживаемых файлов, не произвольное исполнение содержимого.

«Любой формат» не может означать, что любой неизвестный бинарный формат гарантированно читается. UI принимает выбор файла, определяет формат, сообщает о поддержке и предлагает безопасный конвертационный путь.

## Импорт: шаги
1. Выбор одного или нескольких файлов / ZIP.
2. Проверка расширения, сигнатуры и MIME.
3. Проверка размера, числа файлов и безопасности архива.
4. Разбор без изменения библиотеки.
5. Предпросмотр метаданных и глав.
6. Ручное изменение порядка, названий, разделение/объединение глав.
7. Выбор назначения: новое произведение, добавить в черновик, заменить выбранный черновик.
8. Финальное подтверждение.
9. Сохранение оригинала и нормализованного документа раздельно.
10. Отчёт: успешно, пропущено, предупреждения, ошибки.

Никогда не заменять опубликованную главу прямым импортом. Для опубликованного текста — только новый черновик/заявка на изменение.

## Обработка содержимого
- DOCX: стили заголовков, абзацы, выделение, ссылки, изображения и таблицы где возможно.
- EPUB/FB2: оглавление, порядок чтения, метаданные, разделы.
- PDF: текст и порядок страниц; не обещать исходную книжную вёрстку.
- ZIP: показывать дерево; естественная сортировка имён; автор подтверждает порядок глав.
- HTML: удалять script, event handlers, опасные URL, embedded objects.
- Изображения хранить как отдельные ассеты с авторизацией.

## Экспорт
Форматы: DOCX, PDF, EPUB, TXT, RTF, ODT, HTML, Markdown, FB2, ZIP backup.
Объём: всё произведение, выбранные главы, диапазон глав.
Опции: титульный лист, метаданные, оглавление, изображения, разделители глав.
ZIP backup: manifest, метаданные произведения, главы, оригинальные файлы импорта, доступные изображения, версии по выбранной политике.

## Права
В текущем `lib/export.ts` политика разрешает экспорт собственнику, администратору/модератору и public domain; прочий защищённый контент запрещён. Не ослаблять эту политику без отдельного решения правообладателя и security review. Проверка — на сервере перед генерацией и перед скачиванием. Не создавать публичные постоянные ссылки.

## Безопасность
- лимиты размера и количества;
- проверка magic bytes;
- защита ZIP от zip-bomb, path traversal и symlink;
- временные каталоги и изолированный конвертер;
- лимиты CPU/RAM/таймаут;
- антивирусный сканер при доступности;
- санитизация HTML;
- запрет выполнения скриптов из документов;
- временные ссылки и аудит операций;
- не записывать текст рукописей в обычные логи.

## Важное текущее состояние архива
`/api/author/import` поддерживает DOCX, Markdown, TXT, PDF до 15 MiB; PDF без текстового слоя отклоняется. Отдельный `/api/author/import-epub` создаёт черновик произведения и главы из EPUB до 25 MiB. `lib/export.ts` содержит генерацию PDF и проверку прав. Это база, которую нужно расширить, а не объявлять универсальным импортом/экспортом.
