Доходы/донаты остаются в существующей системе и должны быть встроены в навигацию без дублирования данных.

## Экран «Обзор»
- CTA «Продолжить работу» для последней редактируемой главы.
- список последних произведений и их статусы;
- черновики, запланированные публикации и ожидающие проверки;
- мини-график чтений за 7/30 дней;
- уведомления о комментариях;
- состояние синхронизации/резервной копии.

## Экран «Произведения»
- карточка: обложка, название, псевдоним, тип, статус, дата обновления;
- поиск, фильтры по статусу/типу/языку, сортировка;
- создать произведение;
- действия: открыть, редактировать описание, открыть главы, архивировать;
- удаление только через подтверждение с объяснением последствий.

## Мастер создания произведения
Шаг 1 — основное: название, тип (книга/фанфик/комикс/манга/вебтун/другое), язык, псевдоним.
Шаг 2 — оформление: описание, обложка, жанры, теги, серия/том.
Шаг 3 — аудитория: возрастная маркировка, предупреждения о содержании, комментарии.
Шаг 4 — публикация: черновик/публикация, доступ глав, расписание, настройки монетизации только если соответствующие функции уже доступны аккаунту.
Все шаги можно пропустить, кроме обязательного названия и языка; незавершённый мастер сохраняется.

## Экран структуры произведения
- список глав с номером, названием, статусом, количеством слов и датой изменения;
- перетаскивание для порядка, но серверная проверка уникальности номера;
- добавить главу, импортировать главы, массово выбрать;
- перемещение/переименование не должно незаметно менять URL опубликованной главы.

## Экран редактора
Верхняя полоса: название произведения, глава, статус сохранения, назад.
Основная зона: TipTap, ширина чтения, комфортный line-height, фокус на тексте.
Панель инструментов: заголовок/абзац, жирный, курсив, подчёркивание, списки, цитата, ссылка, разделитель сцены, изображение, отмена/повтор.
Нижняя строка: слова/символы, последняя синхронизация, предупреждение о проблемах.
Боковая панель (сворачиваемая): структура глав, заметки, поиск, версии.
Режим без отвлечений скрывает всё, кроме текста и минимальной полосы сохранения.

## Экран «Файлы и перенос»
Вкладки: Импорт, Экспорт, Резервная копия, История операций.
Импорт: зона перетаскивания + выбор файла + поддерживаемые форматы + ограничения.
Экспорт: произведение/главы/диапазон + формат + параметры.
История: дата, операция, файл, результат, предупреждения, повторить если безопасно.

## Статистика
Периоды 7/30/90 дней; фильтр по произведению; просмотры, уникальные читатели, чтения глав, переходы на следующую главу, дочитывания, подписки, оценки, комментарии, доходы. Только агрегированные данные.

## Мобильная навигация
Нижние вкладки: Главная, Произведения, Редактор, Файлы, Профиль.
Внутри произведения — переключатель глав. Редактор занимает весь экран; форматирование открывается компактной нижней панелью. Все действия доступны без hover.
