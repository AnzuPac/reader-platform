# QA и критерии приёмки Author

## Критические сценарии
1. Обычный пользователь активирует роль автора; существующая учётная запись не дублируется.
2. Автор создаёт произведение, добавляет главы, сохраняет и публикует.
3. Автор редактирует черновик; автосохранение переживает обновление страницы.
4. Автор открывает одну главу в двух вкладках; устаревшая запись не перетирает новую.
5. Автор отправляет правку опубликованной главы; публичная версия остаётся прежней до решения.
6. Автор импортирует DOCX с заголовками; предпросмотр показывает главы до записи.
7. Автор импортирует EPUB; порядок глав соответствует spine/TOC, предупреждения видны.
8. Автор импортирует ZIP с файлами в разном порядке; подтверждает порядок вручную.
9. Повреждённый/поддельный файл отклоняется безопасно.
10. ZIP traversal/zip bomb не выходит из временной директории и не расходует бесконтрольные ресурсы.
11. Экспорт собственного произведения разрешён согласно действующей политике.
12. Экспорт чужого защищённого произведения запрещён и через прямой API.
13. Офлайн-редактирование создаёт локальную очередь; восстановление сети синхронизирует изменения.
14. Конфликт устройств сохраняет обе версии и требует решения.
15. Удаление/архивация не уничтожает файл без подтверждения и политики восстановления.

## Форматы — тестовые фикстуры
- DOCX: heading styles, italics, bold, links, image, table, footnotes.
- DOC: корректный legacy sample и файл, требующий конвертации.
- TXT: UTF-8, UTF-16, CRLF, кириллица, сербская латиница.
- RTF/ODT: абзацы, заголовки, ссылки.
- EPUB: TOC, spine, вложенные XHTML, изображения, metadata.
- PDF: text-based, scanned-only, mixed, encrypted/corrupt.
- FB2: title-info, sections, epigraph, annotation.
- HTML: scripts, javascript: URLs, inline event handlers, embedded content.
- ZIP: natural sort, nested folders, duplicate names, traversal, huge expansion ratio.

## Нефункциональные критерии
- типы TypeScript strict проходят;
- существующие тесты не регрессируют;
- тесты SQLite и PostgreSQL покрывают миграции;
- мобильные экраны не имеют горизонтального overflow;
- клавиатурная доступность editor toolbar;
- загрузка/экспорт не блокируют основной web worker;
- логирование не содержит рукопись целиком;
- резервное копирование и восстановление проверены.

## Release gates
Не выпускать импорт/экспорт в production, пока не пройдены security tests для файлов.
Не выпускать офлайн-синхронизацию, пока не пройдены тесты конфликтов.
Не выпускать миграции без проверенного backup/rollback.
