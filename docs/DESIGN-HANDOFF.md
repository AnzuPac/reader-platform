# DESIGN HANDOFF — утверждённый макет и состояние

Источник истины — `docs/prototype/TeroLibrary_Full_Design_Review.html`
(18 экранов). В приложении он перенесён как слой `app/prototype.css`
под scope `.tlp`, переменные `--tlp-*`.

## На макете

```
шапка и подвал     brand, nav, глобальный поиск, язык, уведомления, вход
главная            hero с обложками, «продолжить чтение», четыре направления,
                   рекомендации и топ в каждом, баннер автора
каталог            пять вкладок, фильтры, сортировка, сетка/список,
                   дровер, активные фильтры, счётчик, пагинация
топ                всё время / год / месяц / неделя × четыре категории
профиль читателя   шапка с обложкой и аватаром, вкладки, статистика,
                   история, закладки, достижения с прогрессом, жанры,
                   подписка только владельцу
```

## Не переведено

произведение, читалка, библиотека, подборки, кабинеты автора и издателя,
подписка, аккаунт, уведомления, вход/регистрация, админка,
помощь/правила/о платформе.

## Токены макета

```
ink    #1f2937   основной текст
brand  #6d28d9   акцент
line   #e5e7eb   границы
mist   #6b7280   вторичный текст
panel  #ffffff   поверхности
bg     #f5f6f8   фон
```

Категорийные цвета — в разделе «Категории и цвета» в HANDOFF.

## Состояние в URL

```
q, kind, type, filter, genre, source, tag, fandom, ai, page, period, tab
kind: publisher | selfpub | fanfic | comic | top
period: all | year | month | week
profile tab: overview | library | history | bookmarks | achievements | about
```

Смена языка сохраняет путь и query.
