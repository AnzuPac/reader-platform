# Publisher Studio — критерии приёмки

1. Участник видит только издательство, в котором состоит.
2. Owner видит полную панель и может управлять командой.
3. Manager не может удалить/понизить последнего owner или передать владение.
4. Member не получает финансы и CSV без явного разрешения.
5. Общая статистика ограничена произведениями издательства.
6. Статистика автора ограничена произведениями, относящимися к издательству.
7. Самостоятельные произведения автора не попадают в отчёт издательства.
8. При нескольких издательствах данные не смешиваются.
9. Разные валюты не складываются в одно число.
10. Если событие чтения не измеряется, UI не показывает фиктивный показатель «дочитано».
11. При малой выборке демографический разрез скрывается.
12. CSV содержит те же ограничения и фильтры, что и экран.
13. Подмена `publisherId`/`authorId` в URL не открывает чужие данные.
14. Публичная страница не раскрывает финансовые или неопубликованные данные.
15. Все текущие тесты Publisher API и лицензий продолжают проходить.
