# Доступ к статистике авторов и права

## Область видимости
Издательство получает статистику только по произведениям, у которых `works.publisher_id` соответствует издательству либо существует активная лицензия/связь, разрешающая соответствующий отчёт. Одного совпадения `author_id` недостаточно.

Автор может состоять в нескольких издательствах и одновременно публиковать самиздат. Поэтому нельзя получать всю статистику автора только по `author_id` и показывать её издательству.

## Модель запроса
- publisherId берётся из проверенной сессии/членства, а не доверяется клиенту;
- фильтрация выполняется на сервере в SQL;
- произведения выбираются по разрешённому publisher ownership/license;
- только затем агрегируются события чтения/продаж;
- каждый endpoint проверяет `publisher_members` и роль пользователя.

## Матрица прав (предлагаемая)
| Действие | Owner | Manager | Member |
|---|---:|---:|---:|
| Общая статистика | Да | Да | По разрешению |
| Статистика автора | Да | Да | По разрешению |
| Финансовые отчёты | Да | По разрешению | Нет по умолчанию |
| CSV выгрузка | Да | По разрешению | Нет по умолчанию |
| Каталог и карточки работ | Да | Да | Чтение |
| Сотрудники | Да | Управление без смены владельца | Нет |
| Настройки издательства | Да | Ограниченно | Нет |

Разрешения проверять на сервере, а не только скрытием кнопок.
