# Аудит исходного состояния — что уже есть и что предстоит сделать

Основано на просмотре исходного архива TeroLibrary-reader-full.zip, включённого в комплект. Это статический аудит файлов, не запуск полного production QA.

## Уже найдено в исходном коде
### Author
- Страница кабинета автора `/[lang]/author`.
- TipTap-компонент `ChapterEditor.tsx`.
- Загрузка/редактирование глав, вставка изображений, публикация.
- Импорт DOCX, Markdown, TXT, PDF с ограничением размера и проверкой текста PDF.
- Отдельный EPUB importer.
- Авторские API для работ, глав, публикации, изображений/обложек, статистики, доходов, выплат, донатов.
- Запросы на изменение опубликованных глав.
- Серверная проверка ролей автора/администратора/модератора.
- PDF export policy в `lib/export.ts`; ограничения защищённого контента сохранять.

### Publisher
- Страница `/[lang]/publisher`.
- Внутренние publisher API/guards и роли `owner | manager | member`.
- Работы издательства, участники, лицензии/права, отчёты, выплаты.
- Отчёты включают продажи, выручку, комиссии и роялти.

## Не подтверждено как готовое
- Полная история версий и восстановление с diff.
- Надёжное автосохранение и разрешение конфликтов.
- Расширенный полный список импорт/экспорт форматов.
- ZIP multi-file processing и защищённая изолированная конвертация.
- Offline-first мобильное приложение Author и sync.
- Полноценная читательская аналитика для Publisher.
- Гарантированно корректная аналитическая изоляция по ownership/license.
- Фильтр общего каталога по издательству.

## Важные проверки перед реализацией
- Проверить фактические таблицы и миграции для publisher ownership/license.
- Проверить reader event schema, чтобы определить, какие метрики реально можно показывать.
- Проверить финансовые суммы и валюты, не суммировать валюты без курса.
- Проверить права каждого API endpoint, включая экспорт и скачивание файлов.
- Проверить статусы внутреннего каталога издательства и публикации в общий каталог как отдельные состояния.

## Тесты и сборка
README исходного проекта указывает 292 теста и команды `npm ci`, `npm run test`, `npm run build`, `npm run e2e`. Сам архив не следует считать прошедшим эти проверки в текущей среде: повторный запуск обязателен.
