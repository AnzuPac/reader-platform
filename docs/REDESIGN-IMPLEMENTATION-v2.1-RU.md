# TeroLibrary — реализация дизайн-прохода v2.1

Дата: 26.11.2026  
Исходник: `TeroLibrary-READER-FULL-2026-11-26-v2.zip`

## Цель

Сделать две самостоятельные компоновки одного продукта:

- desktop: просторная композиция по визуальным паттернам Inkwell, но с фирменной палитрой, типографикой, логотипом и функциями TeroLibrary;
- mobile: отдельная мобильная композиция по утверждённому `APPROVED-MOBILE-PREVIEW-v1.0.html`, а не уменьшенная версия desktop.

Общие API, БД, права, авторизация, покупки, чтение, локали и бизнес-правила остаются едиными.

## Зафиксированные визуальные решения

### Новый знак бренда

- Используется новая серая эмблема из Android `app/src/main/assets/logo.png` (полумесяц, книга, перо и звёзды).
- В веб-шапке она отрисовывается прозрачной маской `public/brand-mark-mask.png` и окрашивается через `currentColor`.
- Цвет меняется по текущему разделу:
  - издательские книги — серо-синий;
  - самиздат — синий;
  - фанфики — фиолетовый;
  - графическая литература — оранжевый;
  - Top — нейтральный серо-синий.
- Android launcher icon не перекрашивалась: динамический цвет относится к веб-эмблеме в шапке.
- `app/icon.svg` приведён к новой эмблеме для системной иконки сайта.

### Цвета и темы

Токены берутся из `app/prototype.css`, а не из Inkwell:

- издательства: `#5b6779`;
- самиздат: `#2f6fb7`;
- фанфики: `#9061c4`;
- графика: `#df843b`;
- светлый фон: `#f5f6f8`;
- панели: `#ffffff`;
- текст: `#252832`.

Светлая и тёмная темы используют одну систему компонентов и разные значения токенов. В читалке остаются собственные режимы чтения.

Не заимствуются у Inkwell его wordmark, логотип, бордовый цвет, Circular Std, фотографии, иллюстрации или тексты.

## Изменения в веб-проекте

### Общий каркас и навигация

- `components/SiteHeader.tsx` — обновлённая шапка, новая эмблема, поиск, язык, тема, уведомления, кошелёк/авторизация.
- `components/DirectionTabs.tsx` — прямые направления desktop: издательства, самиздат, фанфики, графическая литература, Top.
- `components/CategoryThemeBinder.tsx` — цвет знака и акцента синхронизируется с текущим разделом каталога/произведения/читалки.
- `components/BottomNavPill.tsx` — мобильная нижняя навигация: Главная / Топ / Каталог / Моя библиотека / Профиль. Поиск остаётся в верхней шапке и открывает отдельный экран.
- `components/Chrome.tsx` — общий каркас сохраняет существующее подключение нижней навигации и тематической привязки.
- `app/layout.tsx` — подключена последняя дизайн-система; viewport `device-width`, `initialScale=1`, `viewportFit=cover`.

### Главная

- `app/[lang]/page.tsx` использует реальные данные каталога.
- Персональная категория рекомендаций определяется по истории чтения, если история достаточна; для нового пользователя используются популярные подборки.
- Популярные теги получают данные из репозитория.
- Для мобильного экрана добавлена отдельная полоса категорий.
- Информация карточки видна без hover: обложка, AI-бейдж, категория, рейтинг/статус, название, автор.
- Существующий блок продолжения чтения сохраняет реальную ссылку и процент прогресса.

### Поиск

- `components/SearchOverlay.tsx` — отдельный overlay с запросом, очисткой, историей, популярными запросами, прямым переходом к расширенным настройкам каталога и списком результатов.
- `app/api/search/route.ts` — серверные подсказки через существующий `listWorks`, с ограничением частоты запросов.
- Полный каталог остаётся канонической страницей результатов с пагинацией и URL-параметрами.
- Текущий `search_norm` индекс покрывает название, автора, теги, жанры, фандом/пейринг и предупреждения; отдельный поиск по полному тексту описания ещё требуется добавить в индекс. Быстрый экран не должен считаться окончательной реализацией поиска по описанию до этой доработки.

### Каталог и карточки

- `components/bookverse/BookverseCatalog.tsx` — изменено представление обложки и карточки; метаданные находятся под обложкой и доступны на сенсорных экранах.
- Главные разделы каталога: Книги / Фанфики / Графическая литература. Книги издательств и самиздат сохраняются как источники внутри книг. Top — отдельный раздел.
- Существующая URL-сериализация, серверная пагинация и серверные фильтры сохранены.
- Кнопка фильтров использует SVG, а не символьную пиктограмму.
- Логика Include/Exclude и AI-фильтров остаётся в текущем репозитории и каталожном контракте.

### Произведение и читалка

- `app/[lang]/work/[slug]/page.tsx` получает категорийный контекст для окраски эмблемы.
- `app/[lang]/read/[id]/page.tsx` также передаёт тип произведения читалке.
- `lib/repo.ts` включает `work_kind` в данные главы, чтобы правильно классифицировать фанфик/графическую главу.
- Существующий механизм чтения, доступ к главам, прогресс, комментарии и настройки не заменяются макетными действиями.

### Рабочие кабинеты

- `app/[lang]/author/page.tsx` — новое рабочее пространство с боковой навигацией desktop, компактным меню mobile, KPI из данных автора, активностью и последними произведениями.
- `components/AuthorWorks.tsx` — сохранён существующий функционал произведений и формы; добавлен стабильный якорь редактора.
- `app/[lang]/publisher/page.tsx` — внутренний кабинет издательства с боковой навигацией, отчётами, произведениями, правами, лицензиями, командой и выплатами.
- Существующие редакторы цен/прав, отчёты, участники, лицензии и выплаты сохранены.
- Кабинет издательства остаётся внутренним, без публичной витрины.

### Адаптивные стили и иконки

- `styles/design-system-v2.css` — последний слой общей дизайн-системы desktop/mobile.
- `public/brand-mark-mask.png` — маска новой эмблемы.
- `app/icon.svg` — иконка сайта с новой эмблемой.
- CSS прежних этапов v1.1–v1.3 остаётся подключённым, но новый слой подключён последним, чтобы переопределять устаревшие мобильные ограничения.

## Адаптивные правила

- 1440 px: desktop-компоновка, просторные сетки, боковые панели кабинетов.
- 768 px: планшетный переход, горизонтально прокручиваемая навигация без выхода за ширину.
- 390 px и уже: отдельный phone layout, компактная шапка, скрытая desktop-навигация, плавающая нижняя панель и safe-area.
- Глобальная горизонтальная прокрутка запрещена.
- Нижняя панель не должна перекрывать конец контента; читалка и кабинеты получают дополнительный нижний отступ.
- Карточки не полагаются на hover.

## Ограничения текущего прохода

- Android исходники и исходный APK включены в пакет; APK не пересобирался.
- Изменения веб-шапки и сайта будут видны в WebView после публикации обновлённого сайта; для APK-пакета отдельно потребуется прогон на реальном устройстве.
- Не выполнялись полный TypeScript `tsc --noEmit`, Vitest, `npm run build` и browser end-to-end: Node в рабочей среде `22.16.0`, проект требует `22.22.2+`, зависимости не установлены.
- Перед production обязательны полная установка зависимостей на Node `22.22.2+`, тесты, сборка, ручной проход SR/RU/EN, light/dark и проверка WebView на реальном Android.
