# Reader Platform — спецификация v0.1

Платформа чтения: произведения (Wattpad-структура), оформление в духе Webnovel,
подписки, ИИ-перевод, сканер книг, хранилище. Комиксы — вторым этапом.

Дата: 9 ноября 2026. Статус: черновик для согласования.

## 1. Роли

| Роль | Права |
|---|---|
| **reader** | читает бесплатное, покупает подписку, ведёт библиотеку и закладки, комментарии |
| **author** | всё выше + создаёт произведения, главы, видит статистику своих работ |
| **translator** | переводит главы на выбранный язык (внутренняя роль) |
| **moderator** | жалобы, скрытие комментариев, блокировка работ |
| **admin** | полный доступ, тарифы, пользователи, настройки |

Автор не публикуется напрямую: черновик → проверка → публикация (для качества каталога).

## 2. Контент-модель

```
work (произведение)
 ├── work_translation (языковая версия: sr / en / ru)
 ├── volume (том, опционально)
 ├── chapter (глава: номер, название, текст, цена-доступ)
 │    └── chapter_translation (перевод главы на язык)
 ├── genre / tag (многие-ко-многим)
 └── comment (дерево комментариев)
```

- **work** — обложка, название, описание, автор, статус (ongoing / completed), возрастной рейтинг, язык оригинала
- **volume** — нужен для длинных серий и для комиксов позже
- **chapter** — упорядочен по номеру; текст хранится как Markdown/HTML-фрагмент
- **доступ к главе**: `free` | `subscribers` | `paid` (разовая покупка)
- **комиксы (позже)**: `chapter_page` (номер страницы, файл картинки, ширина/высота)

## 3. Пользователь и прогресс

- `user` — email + пароль (argon2), либо OAuth (Google/Discord)
- `library` — «в библиотеке» с датой добавления
- `reading_progress` — произведение, глава, позиция (символ/абзац), процент, время чтения
- `bookmark` — закладка на позицию в главе
- `rating` — 1–5 звёзд, одна оценка на пользователя на произведение
- Прогресс синхронизируется при каждой смене главы и раз в 30 секунд внутри главы

## 4. Подписки и доступ

### 4.1 Тарифы
- **Free** — бесплатные главы, реклама, квота хранилища 1 ГБ
- **Reader** — все главы «subscribers», без рекламы, 5 ГБ
- **Reader+** — всё выше, ранний доступ к новым главам, 20 ГБ

### 4.2 Сущности
- `plan` — код, название, цена, период (месяц/год), лимиты
- `subscription` — user, plan, статус (active / past_due / canceled), период начала и конца
- `entitlement` — выданный доступ: к главе (`chapter`) или ко всему произведению (`work`), с источником (`subscription` | `purchase` | `grant`)
- `payment` — счёт/оплата: сумма, валюта, метод, внешний id, статус

### 4.3 Правило проверки доступа
```
доступ к главе, если:
  chapter.access = 'free'
  ИЛИ есть entitlement на главу/произведение
  ИЛИ активна подписка нужного уровня и chapter.access = 'subscribers'
```

Проверка **только на сервере**. Клиент никогда не получает текст платной главы без проверки.

### 4.4 Оплата (этап 2)
Сначала — ручная: админ выставляет счёт, отмечает оплату, система выдаёт подписку.
Потом — Stripe Payment Link / Checkout; вебхук `checkout.session.completed` → `payment` + `subscription`.

## 5. Читалка

- База: **Readium** (BSD-3) для EPUB-совместимого рендеринга текста; для веб-каталога — собственная обёртка
- Режимы: постраничный и прокрутка, размер шрифта, межстрочный интервал, тема (тёмная/светлая/сепия)
- Оглавление, прогресс-бар, переход по номеру главы
- Кнопка «следующая глава», автосохранение позиции
- Рекламный блок: между главами для Free (не внутри текста)

## 6. ИИ-перевод

### 6.1 Что переводим
Главу целиком, абзацами с сохранением разметки. Переводы кэшируются: `chapter_translation` (глава + язык + хэш исходника).

### 6.2 Пайплайн
1. Разбиение на абзацы, нормализация
2. Проверка кэша по `sha256(текст + язык + версия промпта)`
3. Перевод с контекстом (краткое содержание предыдущей главы + глоссарий)
4. Второй проход: вычитка на стиль и терминологию (без изменения смысла)
5. Сохранение: перевод, глоссарий новых терминов, статус (`draft` / `approved`)

### 6.3 Промпт
Каркас взят из Tormund (`gm_ru_v4.md`): теги `<system_prompt>`, `<role>`, `<output_format>`, `<rules>`,
строгий JSON на выходе. Адаптация: роль «литературный переводчик», правила стиля, запрет добавления
сюжета, обязательное сохранение имён из глоссария.

### 6.4 Модель
Локальная (Ollama) по умолчанию — 0 стоимости. Облачная — опционально, настраивается на уровне платформы.

### 6.5 Ограничения
- перевод чужих лицензионных произведений — производная работа, нужно разрешение правообладателя
- при публикации перевода указывается «перевод ИИ» и возможность сообщить об ошибке

## 7. Сканер книг и хранилище

### 7.1 Сканирование (на устройстве)
1. Камера → серия кадров страниц
2. Обрезка, выравнивание, коррекция перспективы (на устройстве)
3. OCR локально (ML Kit / Vision / Tesseract-wasm)
4. Сборка PDF (с текстовым слоем) или EPUB
5. Загрузка в облако пользователя или сохранение локально

Сервер не выполняет OCR — только принимает готовый файл.

### 7.2 Хранилище
- S3-совместимое (MinIO локально, S3/Backblaze в проде)
- Квоты: Free 1 ГБ, Reader 5 ГБ, Reader+ 20 ГБ
- Таблица `storage_file`: владелец, размер, тип, путь, ссылка на сущность (книга/скан)
- При превышении квоты загрузка блокируется, пользователю показывается занятое место
- Доступ к файлам — по подписанным ссылкам с ограниченным временем

## 8. Реклама для бесплатных

- Слоты: `catalog_bottom`, `chapter_between`, `chapter_end`
- Конфиг слота: код вставки (HTML/скрипт), активность, страны, тарифные ограничения
- Free видит рекламу, подписчики — нет
- AdSense не подходит для 18+ контента → предусмотреть отдельные пулы: обычный пул и пул «без AdSense»

## 9. Языки (i18n)

- Интерфейс: **sr** (по умолчанию обсудить), **en**, **ru**
- Маршруты: `/{lang}/…`, переключатель, запоминание выбора
- Контент: язык оригинала + переводы; фильтр каталога по языку
- SEO: отдельные `hreflang`, мета-описания на каждом языке

## 10. Технический стек

| Слой | Выбор | Почему |
|---|---|---|
| Веб | Next.js (App Router) + TypeScript | SSR/SEO, знакомый стек (Юрей) |
| БД | PostgreSQL | реляционные связи, транзакции подписок |
| ORM | Drizzle | типы без магии, миграции в git |
| Сессии | JWT в httpOnly cookie + refresh | как в CRM, проверка на сервере |
| Файлы | S3 (MinIO/S3) | подписанные ссылки, квоты |
| Кэш/очереди | Redis (позже) | очереди перевода, кэш каталога |
| Поиск | Postgres FTS + trgm | без внешнего сервиса на старте |
| Перевод | Ollama (локально) | 0 стоимости |

## 11. Границы MVP (первая версия для продаж)

Входит:
1. Регистрация/вход, профиль, смена пароля
2. Каталог: карточки, жанры, теги, поиск, сортировки
3. Страница произведения, оглавление
4. Читалка текста с прогрессом и настройками
5. Админка: произведения, главы, публикация
6. Подписка: тарифы, ручная оплата, ограничение платных глав
7. Рекламные слоты для Free
8. Юридические страницы (условия, политика, правила)

Не входит: комиксы, ИИ-перевод, сканер, хранилище, приложение.

## 14. Риски

- **Права на контент** — главный юридический риск, особенно для комиксов и переводов
- **Оплата из Сербии** — Stripe требует юрлица/посредника; на старте ручные счёта
- **Спам-регистрации** — нужен rate limit и проверка email
- **Нагрузка на чтение** — кэш глав и CDN для статики
