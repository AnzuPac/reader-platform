# Демо-сценарий — 10–12 минут

Показ для издателя: три потока (книга по покупке, фанфик с донатом, комикс по главам),
кабинет издателя и админка издательств. Всё на локальной машине, без Stripe.

## Подготовка (за 5 минут до показа)

```bash
cd ~/.openclaw/workspace/reader
node scripts/seed-demo.mjs          # демо-данные, можно запускать повторно
ADMIN_TOKEN=dev-admin-token npm run start   # http://localhost:3020
```

Открыть в браузере заранее:

- `http://localhost:3020/sr` — главная
- `http://localhost:3020/sr/catalog` — каталог
- `http://localhost:3020/sr/admin` — админка (вкладка «Покупки»)
- `http://localhost:3020/sr/admin/publishers` — издательства

Токен админки: значение `ADMIN_TOKEN` (локально `dev-admin-token`), вставляется в поле
«Токен доступа» на странице админки.

Демо-логины (пароль у всех `demo1234`):

| Роль | Логин |
|---|---|
| Читатель (с историей) | `demo.reader@example.com` |
| Новый покупатель (чистый) | `demo.buyer@example.com` |
| Владелец издательства | `demo.publisher@example.com` |
| Автор фанфика | `demo.author@example.com` |

## Поток 1. Книга по покупке (3–4 мин)

1. Войти как `demo.buyer@example.com` → `/sr/login`.
2. Открыть `/sr/work/senke-starog-grada`.
   - Показать: описание, глава 1 бесплатная, главы 2–3 с замком, цена 15,00 EUR.
3. Нажать «Kupi knjigu» (купить книгу).
   - Ожидаемо: «Zahtev #… je poslat. Uplata 15,00 EUR na račun izdavača; pristup se
     otvara posle potvrde» — Stripe выключен, режим ручного подтверждения.
4. Переключиться в админку `/sr/admin`, вкладка «Покупки».
   - Показать заявку: пользователь, книга, 15,00 EUR, provider `manual`.
   - Нажать «Подтвердить».
5. Вернуться на страницу книги, обновить.
   - Ожидаемо: главы 2–3 без замка, открывается чтение.
6. Открыть главу 2 — текст читается, работает прогресс/настройки читалки.
7. В кабинете издателя (поток 4) позже показать, что продажа попала в отчёт и роялти.

> Если нужно повторить: покупать у `demo.buyer` больше нечего — используйте
> `demo.reader@example.com` для другой книги/главы или пересоздайте БД.

## Поток 2. Фанфик с донатом (2–3 мин)

1. Остаться читателем (или войти `demo.reader@example.com`).
2. Открыть `/sr/work/nocna-straza` — фанфик «Noćna straža», главы бесплатные.
3. Нажать «Podrži autora», выбрать 5,00 EUR, добавить сообщение, отправить.
   - Ожидаемо: заявка создана, автору обещано 90% после подтверждения, площадка 10%.
4. Админка `/sr/admin` → вкладка «Донаты» → «Подтвердить».
   - Ожидаемо: сообщение «автору 4,50 EUR».
5. Войти как `demo.author@example.com` → `/sr/author`.
   - Ожидаемо: донат в списке, баланс автора вырос; в демо уже есть 3 оплаченных доната.
6. Показать форму выплаты автору (заявка на вывод) — деньги не уходят автоматически.

## Поток 3. Комикс по главам (2–3 мин)

1. Открыть `/sr/work/krvavi-mesec`.
   - Показать: глава 1 бесплатная, главы 2–3 по 3,00 EUR.
2. Открыть главу 2 → замок, цена главы 3,00 EUR → «Kupi glavu».
3. Админка → «Покупки» → подтвердить заявку на 3,00 EUR.
4. Вернуться в главу 2, обновить.
   - Ожидаемо: постраничный комикс-ридер, 3 демо-страницы, листание/зум.
5. Отметить: доступ проверяется на сервере, страницы locked не отдаются в API.

## Поток 4. Кабинет издателя и админка издательств (2–3 мин)

1. Войти `demo.publisher@example.com` → `/sr/publisher`.
   - Показать: «Demo Izdavaštvo», комиссия 25%, книга «Senke starog grada»,
     продажи, роялти (75% от 15,00 EUR = 11,25 EUR), период отчёта.
   - Показать редактор цены книги (изменение цены без деплоя).
2. Войти админом (или отдельная вкладка) → `/sr/admin/publishers`.
   - Список издательств: комиссия, число книг, владелец.
   - Создать издательство: название, email, комиссия, email владельца — владелец
     привязывается по email.
   - Привязать произведение к издательству и задать цену книги.
   - Заявки с лендинга: имя, издательство, email, телефон, сообщение; кнопка
     «обработано» переводит заявку в `contacted`.
   - Ссылка «открыть» ведёт в кабинет издателя.

## Что говорить издателю (блок на 2 минуты)

**Защита**
- Платный текст не индексируется и не кешируется (`no-store`), доступ проверяется
  на сервере на каждую главу; в HTML нет скрытого текста закрытых глав.
- Невидимый водяной знак с ID читателя — копию можно связать с аккаунтом.
- Лимит запросов на текст и мягкий лимит 3 устройств; копирование платного текста
  заблокировано, доступность для скринридеров сохранена.
- В пилоте: автоматическое выявление массового скачивания, процесс жалоб, опция
  видимого водяного знака, внешний DRM только при реальной необходимости.

**Сербские платежи**
- Сейчас: ручное подтверждение (перевод на счёт издателя) — работает без Stripe.
- Дальше: карточный эквайринг (Stripe/локальный провайдер), подписка и разовые
  покупки; деньги и роялти считаются в центах, без float.
- Комиссия площадки фиксируется в процентах у издательства; смена ставки не
  пересчитывает историю.

**Роялти**
- Продажа книги: площадка берёт комиссию издательства (демо — 25%), остальное —
  роялти издателя; начисление попадает в ledger в момент подтверждения оплаты.
- Фанфики: донат, площадка 10%, автор 90%; выплаты — отдельными заявками.
- Отчёт по периодам и по произведениям, выплаты фиксируются отдельно.

**Пилот**
- 3–6 названий, без эксклюзивности, 6–8 недель.
- Цель: проверить конверсию покупки книги, донаты и удержание на комиксах.
- Метрики: продажи, дочитываемость, возвраты, средний чек, донаты на автора.

## Если что-то не открылось

- `/api/health` должен вернуть `{ok:true, db:"up"}`.
- 403 в админке — неверный `ADMIN_TOKEN` в поле токена.
- Пустой каталог — не запущен `seed:demo` или сервер смотрит в другую БД
  (`DATABASE_URL` / `SQLITE_DIR`).
- Покупка уже оплачена — у пользователя есть доступ; для живой покупки берите
  `demo.buyer` и другую цель.
