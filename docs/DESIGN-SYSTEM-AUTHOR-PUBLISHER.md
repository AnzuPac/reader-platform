# Единая дизайн-система TeroLibrary для Reader, Author и Publisher

Версия 1.0 · 25.11.2026

## Принцип
Author Studio и внутренний Publisher Studio — части TeroLibrary, а не самостоятельные продукты с отдельным визуальным языком. Повторно использовать существующие токены, компоненты, типографику, состояния и паттерны из `TeroLibrary-web/app/globals.css` и текущей читалки. Не вводить отдельную бежево-коричневую тему.

## Базовые токены текущего web-проекта
- Фон: `--rd-bg: #ffffff`.
- Основной текст: `--rd-fg: #1f2937`.
- Вторичный текст: `--rd-muted: #6b7280`; дополнительный приглушённый: `--rd-mist: #4b5563`.
- Разделители: `--rd-line: #e5e7eb`; мягкая поверхность: `--rd-surface-soft: #f9fafb`.
- Поля: `--rd-field-line: #d1d5db`; текст поля: `--rd-field-fg: #111827`.
- Основной акцент web: `--rd-accent: #111827`; фокус: `--rd-focus: #2563eb`.
- Базовая карточка: белая поверхность, тонкая нейтральная рамка, радиус 12px, лёгкая тень.

## Совместимость с текущей читалкой
В Android preview используется нейтральная светлая оболочка `#f5f6f8`, белые панели, холодные серо-голубые акценты (`#71809a`, `#53647e`), мягкие фоновые поверхности (`#eef1f6`), а также категорийные цвета: manga blue, fanfic purple, orange для отдельных акцентов. Эти оттенки допустимы в соответствующих контекстах; они не заменяют базовые web-токены.

## Компоненты
- Кнопки: использовать `.btn`, `.btn-primary`, `.btn-ghost`; одинаковые высоты, радиусы и focus-visible.
- Поля: `.input`, нейтральная рамка, синий focus ring.
- Карточки: `.card`, без тяжёлых теней и декоративных градиентов.
- Бейджи статусов: нейтральные серые; цвет — только для реального статуса (ошибка, успех, публикация).
- Обложки произведений могут сохранять художественные градиенты/изображения: это контент, а не фон интерфейса.
- Заголовки, иконки, меню, таблицы, фильтры, диалоги и пустые состояния должны повторять компоненты читалки.

## Авторская среда
Редактор может иметь собственную рабочую компоновку (широкая колонка текста, боковая панель главы, верхняя панель инструментов), но визуальные элементы остаются теми же: белые/нейтральные поверхности, типографика TeroLibrary, общие кнопки и поля. Режим без отвлечений убирает навигацию, но не меняет тему.

## Кабинет издательства
Внутренний кабинет использует ту же оболочку и компоненты. Таблицы, графики, фильтры, финансовые сводки и списки авторов не получают отдельную «корпоративную» тему. Не создавать публичную витрину издательства.

## Запреты
- Не использовать отдельную бежевую/коричневую палитру для Author/Publisher.
- Не создавать новый логотип или отдельный бренд для Author Studio.
- Не менять визуальный стиль существующей читалки ради кабинетов.
- Не переносить категорийные цвета на глобальные кнопки и основные поверхности.
