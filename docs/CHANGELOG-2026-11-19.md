## Безопасность и целостность

- `lib/secrets.ts`: в production нет дефолтных JWT-секрета и админ-токена;
  админ-токен короче 32 символов закрывает админку, а не «слегка защищает».
- Админ-сессия: обмен токена на HttpOnly-cookie, лимит 5 попыток / 5 минут.
- Refresh-токены: в БД только sha256-хеш, атомарное потребление через
  `UPDATE ... RETURNING` — параллельный запрос не может использовать тот же токен.
- Rate limit: один атомарный upsert с `RETURNING` вместо check-then-update;
  `X-Forwarded-For` не доверяется без `TRUST_PROXY=1`; Caddy выставляет `X-Real-IP`.
- Stripe webhook: без секрета подписи события не принимаются; неподписанные — 400.
- Роль и статус пользователя читаются из БД для чувствительных действий.
- Журнал миграций: ошибки не проглатываются, `/api/health` отдаёт 503 при сбое.
- Найден и исправлен дефект: Postgres-DDL (`BIGSERIAL`, `TIMESTAMPTZ`) попадал
  в SQLite-список миграций; теперь проверяется отдельным скриптом до сборки.

## Читатель

- Каталог: серверные фильтры и пагинация, состояние в URL; Popular = прочтения,
  Fresh = дата, Completed = оценка; честная подпись «Discover/Подборка/Otkrij».
- Поиск: нормализация и транслитерация, а также фандом, пейринг, предупреждения
  и названия жанров.
- Библиотека: статусы «читаю / в планах / прочитано / любимое / отложено / брошено»
  со счётчиками и сменой статуса у карточки.
- Коллекции: системные, редакционные, пользовательские; публичные и приватные,
  порядок, права владельца, идемпотентные системные подборки.
- Отзывы: только при прогрессе ≥10%, одна запись на пользователя, оценка
  синхронизируется с общим рейтингом.
- Профили: `/[lang]/u/[id]`, био и аватар (только собственные `/uploads/...`),
  приватность, подписка на автора и лента новых глав в уведомлениях.
- Озвучка (TTS) только при `works.tts_allowed`; скачивание глав отсутствует
  намеренно — локальная копия платного текста = способ пиратить.

## Автор, издатель, модерация

- Даты рождения: обязательная при регистрации, проверка возраста (13+),
  наружу не отдаётся, возрастные группы в статистике автора маскируются
  при аудитории ≥20 человек.
- Подарки на день рождения: `app_settings` + `birthday_gifts`, окно вокруг даты,
  один раз в год, только по явному действию; по умолчанию выключены.
- Издатель: роли owner/manager/member (нельзя оставить издательство без
  владельца), лицензии с территорией, сроком и правами (продажа/подписка/
  библиотека/TTS/транслитерация/экспорт), режим защиты Standard/Enhanced
  с честной пометкой «DRM не подключён».
- Жалобы: типы work/comment/review/user, дедупликация открытой жалобы,
  решения (отклонить/скрыть), журнал `resolved_by`, очередь `/[lang]/admin/reports`.
