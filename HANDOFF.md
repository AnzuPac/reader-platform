# HANDOFF — дизайн сайта (состояние 20.11.2026)

Архив собран из git-коммита `2c67a56` (ветка `main`).
Внутри — репозиторий и карта дизайна: без `node_modules`, `.next`, баз и секретов.

## Где живёт дизайн

```
docs/prototype/TeroLibrary_Full_Design_Review.html   утверждённый макет, 18 экранов
app/prototype.css                                    его CSS, изолирован под .tlp
app/[lang]/layout.tsx                                шапка и подвал по макету
app/[lang]/page.tsx                                  главная
components/bookverse/BookverseCatalog.tsx             каталог и вкладка «Топ»
app/[lang]/u/[id]/page.tsx                           профиль читателя
app/globals.css + styles/bookverse.css               старые слои, Tailwind
```

Слой макета подключается в `app/layout.tsx`. Переменные — `--tlp-*`,
все правила — только под `.tlp`, поэтому Tailwind и старые стили не конфликтуют.

## Что уже на макете

```
шапка/подвал   brand, nav, глобальный поиск, язык, уведомления, вход
главная        hero с обложками, «продолжить чтение», четыре направления,
               рекомендации и топ в каждом, баннер автора
каталог        пять вкладок, фильтры, сортировка, сетка/список, дровер,
               активные фильтры, счётчик, пагинация
топ            всё время / год / месяц / неделя, четыре категории
профиль        шапка с обложкой, вкладки, статистика, история, закладки,
               достижения, жанры, подписка только владельцу
```


```bash
curl -s https://terolibrary.com/sr/catalog | grep -c "subnav-btn"
```
